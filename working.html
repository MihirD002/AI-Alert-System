Timeline

The process kicks off by gathering various sources and videos. These videos are transformed into a dataset, setting the stage for model training. The training phase educates the machine learning models. After successful training, predictions are organized into an Excel sheet for streamlined storage. This sheet is then imported into the backend database. Lastly, a messaging system is implemented for user notifications, completing the workflow.
